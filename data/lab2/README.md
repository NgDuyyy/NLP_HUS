# Lab2 Data Notes

- `raw/`: chứa các mảnh dữ liệu C4 (.json.gz). Không commit file thật, chỉ giữ script hoặc hướng dẫn tải.
- `results/`, `results_alt/`: nơi lưu vector TF-IDF và output pipeline.
- `log/`, `log_alt/`: log chạy Spark.

Các thư mục con này được ignore để tránh đẩy file lớn lên Git. Thêm mô tả mới nếu tạo pipeline khác.

# Lab5 Data Notes

- `hwu/`, `hwu_encoded/`: chứa dataset HWU 64 intents ở định dạng gốc và đã mã hoá.
- `models/`: các trọng số TF-IDF, Word2Vec, LSTM.
- `pos_rnn/`, `ner_bilstm/`: kết quả và checkpoint cho các phần mở rộng Lab5.

Các thư mục trên được `.gitignore` bỏ qua. Khi cần chia sẻ dữ liệu, chỉ commit mô tả schema hoặc script tải.
